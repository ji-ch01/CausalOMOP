# FastOMOP Causal Reasoning Extension — Historical Design Record

This file preserves the location of the original Draft v1 design proposal. The
proposal has been superseded by the implemented CausalOMOP workflow and is no
longer maintained as a parallel architecture specification.

Use the following current documents instead:

- [project overview and setup](README.md);
- [causal package implementation status](causal/README.md);
- [normative causal roadmap](docs/causal_roadmap.md);
- [current architecture diagrams](docs/project_architecture_diagrams.md);
- [FastOMOP and OMCP integration](docs/fastomop_integration.md).

The durable ideas from the original proposal remain part of the project:
scientific design precedes extraction, LLM output is always provisional,
clinical mappings require human review, OMOP access is governed, and causal
claims require explicit estimands, diagnostics, and sensitivity analysis.

The obsolete SNUH-only cohort prototype and the earlier plan to place all
causal responsibilities inside FastOMOP are intentionally not reproduced here.
Git history remains the source for the full original draft.
